# Separation Kit - Permission Plugin Project

## Objetivo
Este kit consolida os insumos para iniciar o novo plugin de permissões e bloqueios, mantendo no `ebenezerclone` apenas o domínio de clonagem.

## Conteúdo
- `dre/DRE_PLUGIN_PERMISSION_CORE.md`: DRE inicial do novo projeto.
- `prompts/PROMPT_MASTER_IMPLEMENTACAO.md`: prompt mestre para implementação no Codex.
- `prompts/PROMPT_VALIDACAO_QUALIDADE.md`: prompt de validação técnica e funcional.
- `prompts/PROMPT_RISCO_E_ROLLBACK.md`: prompt de risco, rollout e rollback.

## Escopo desta fase
- Sem versionamento/release.
- Sem criação do novo plugin ainda.
- Preparação técnica e documental para execução controlada em projeto dedicado.
